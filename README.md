# Unsloth Video Translate

*AI & Vibecode*

Дубляж видео через использование Unsloth API:
1) отделение аудиодорожки с голосом
2) транскрибация сказанного с разделением на говорящих и таймкоды
3) перевод с "английского" на "русский" язык LLM, загруженной на Unsloth API
4) озвучка с клонированием голоса каждого говорящего

Данное Web-приложение запускается в Docker на порту http://localhost:7777. Адрес API и ключ указываются вручную в файле `.env`. В интерфейсе: дропбокс загрузки видео; отображаются шаги обработки. По завершении на странице озвученное видео доступно для прямого просмотра и скачивания. Готовые видео хранятся в `storage/`, рабочие файлы задач (прогресс, дорожки, сегменты) — в `work/`. Оба каталога примонтированы из хоста, поэтому данные переживают пересборку и перезапуск контейнера; оборванные задачи после перезапуска продолжают работу с сохранённого шага.

## Запуск

```bash
cp .env.example .env
nano .env

docker compose up -d --build
```

Примечание: для рработы в Unsloth должны быть скачаны или загружены модели для использования, например:
- Разделение: BS-RoFormer-ep368-GGUF · Q8_0
- Транскрибация: MOSS-Transcribe-Diarize-GGUF · BF16
- Клонирование: Qwen3-TTS-12Hz-1.7B-Base-GGUF · Q8_0_V2

Остановка: `docker compose down` (данные в `storage/` и `work/` при этом сохраняются).
